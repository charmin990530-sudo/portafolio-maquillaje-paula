# Jers Beauty Lab

Portafolio web para una maquilladora, con galería de trabajos, avatar interactivo y formulario de cotización por WhatsApp.

## Stack

React, TypeScript, Vite, Tailwind y Motion. Las imágenes y los recursos se sirven de forma local.

## Desarrollo

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
npm run preview
```

## Demo

[Ver el sitio publicado](https://portafolio-maquillaje-paula.vercel.app/)

El formulario prepara el mensaje y deja que la persona confirme el envío en WhatsApp. No guarda datos en este repositorio.
